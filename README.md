Ohwhere Money Go - OwMG
====

##这是一个纯py记账软件，练习用

----

#基础功能
1. 主菜单
    * 启动时显示
    * 数字/字母选择
2. 添加 收/支 记录
    * 输入金额
    * 收支类别
    * 备注(可选)(default = N/A)
    * 自动录入当前时间
    * 每条记录唯一ID
>金额：校验纯数字
收支类别：吃喝/玩乐/衣/住/行/其他（仅选择）
备注：default = ""
时间：年/月/日
#第一条记录后恭喜用户开始记账

3. 记录(数据)存储
    * 记录后保存
    * 启动时加载
4. 查看记录
    * 显示总收支&结余
    * 对于各记录：显示“ID 日期 类别 金额 备注”
    * Options/Settings for user（可选）
5. 删除记录
    * 根据ID删除
6. 搜索记录
    * 精准匹配（后期升级模糊）
    * 匹配 ID/日期/金额/备注 寻找

#不太基础的功能
1. 空 の 提示
    * 查阅时不返回空而是非报错/警告提示：没有账目，但是你发现了一条小蛇/Snake Only
> see,snake:b
(   )
(   )
(. .)

2. 修改记录
    * 根据 ID 选择要修改的记录
    * 二次确认
    * 修改后重加载数据
3. 筛选统计
    * 按年/月
4. 临时备份
    * 仅保存上一次更改后的数据
    * 防止意外退出
    * 与数据文件对比不一样时询问是否更新为备份文件
